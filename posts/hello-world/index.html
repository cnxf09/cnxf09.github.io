    熵

    随机变量 \(X\) 的熵 \(H(X)\)，定义为描述 \(X\) 所需比特数的期望。

    import math

def entropy(ps):
    return -sum(p * math.log2(p) for p in ps if p > 0)

print(entropy([0.5, 0.5]))  # 1.0
