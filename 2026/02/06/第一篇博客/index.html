本地预览

写完文章后，先在本地预览效果：

浏览器访问 http://localhost:4000 即可查看。修改文件后刷新页面就能看到变化，不需要重启。

预览完按 Ctrl + C 停止服务器。

部署上线

确认无误后，一行命令部署到 GitHub Pages：

  • hexo clean — 清除缓存和旧的生成文件
  • hexo deploy — 生成静态文件并推送到 GitHub

部署完成后稍等一两分钟，访问你的博客地址就能看到更新了。

常用命令速查

命令 作用
hexo new "标题" 创建新文章
hexo new draft "标题" 创建草稿
hexo publish "标题" 草稿转正式文章
hexo server 启动本地预览
hexo clean 清除缓存
hexo deploy 部署到线上
hexo clean && hexo deploy 清除缓存并部署（推荐）

小结

Hexo 的日常工作流其实很简单：新建 → 写作 → 预览 → 部署，四步搞定。Markdown 的写作体验也很舒服，专注内容本身就好。
